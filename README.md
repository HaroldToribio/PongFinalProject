# Harold's Pong

A retro Pong game developed in Python using Pygame.

## Features

- Main Menu
- Start Game
- High Score System
- Retro Arcade Graphics
- Ball Collision Physics
- Persistent High Scores

## Technologies Used

- Python 3
- Pygame

## How to Run

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```
